## 7. 공개되지 않은 항목과 시뮬레이션 처리

| 항목 | 처리 |
|---|---|
| 단별 건조·추진제 질량 | 2.1절 추정값을 쓰고, 단 분리 시각·고도에 맞게 건조 질량을 배분 **[근사]** |
| 피치 프로그램·유도 법칙 | 수직 상승 → T+10 s 피치 킥 → 중력 선회(1·2단) → 3단 선형 탄젠트 유도로 700 km 원궤도에 맞춤 **[근사]** |
| 발사 방위각, 수치 지상궤적 | 목표 경사각 98.2°와 지구 자전으로 방위각 약 193°를 계산 **[근사]** |
| 고도·속도 시계열 | 공개된 이벤트 고도(62 / 202 / 약 265 / 700 km)를 맞추는 것을 검증 기준으로 사용 |
| 추적소 정밀 좌표 | 공개 지명 기준 근사 좌표 **[근사]** |
| 페어링 외형 | 내부 공간(2.7 m × 4 m)과 2단 직경 2.6 m로 외형을 설계 **[근사]** |
| 엔진 스로틀링, 짐벌각 | 1단은 일정 추력, 자세는 이상적 제어로 가정 **[근사]** |

검증 목표: 1단 분리 123 s / 62 km, 페어링 227 s / 202 km, 2단 분리 269 s / 약 265 km, 3단 종료 약 790 s / 700 km, 경사각 약 98.2°, 최대 가속도는 설계 기준 4.3 G [17] 이하.
